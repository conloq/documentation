# Pesquisa de usuário (IHC)

- [Mapa de Empatia do Mash](mapa-de-empatia-mash-hipotetico.pdf): hipótese inicial sobre o pequeno produtor de cerveja artesanal. Versão 1.0, de 20/10/2026. Não representa entrevista nem validação com usuários.
- [Template de Mapa de Empatia](template-mapa-de-empatia.pptx): material de referência da disciplina de IHC da FATEC Registro. É um modelo da atividade, não o arquivo-fonte editável do mapa do Mash.

A [pesquisa de usuário (#77)](https://github.com/conloq/mash/issues/77) ainda requer entrevistas com 2 a 3 pessoas, autorização para as evidências multimídia, análise das respostas e personas criadas a partir dos dados coletados. O mapa pode orientar as perguntas; hipóteses só serão confirmadas após a pesquisa.
